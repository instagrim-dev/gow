# Findings

Research findings say **what experiments have actually shown** — abstracted from
the immutable experiment records that produced them, and disciplined by the
[epistemic model](../theory/02-epistemic-model.md).

A finding is not an experiment record. The experiment record (under
[`corpus/experiments/`](../../corpus/experiments/)) is the frozen protocol,
arms, adjudication, and verdict. A finding is a scoped, citable claim about *what
was observed*, held to the verification hierarchy: model-judged findings are
labeled as such and never presented as verified.

A single experiment can be **negative under its own frozen effectiveness
criterion** while still producing a **positive capability finding** about one
constituent operation. Keeping the two apart is exactly why this directory
exists.
