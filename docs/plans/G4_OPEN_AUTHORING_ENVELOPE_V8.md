# G4 open authoring envelope v8

This contract is for public synthetic delivery testing only. It authorizes no
protected authoring, protected response inspection, protected retry, G4
execution, grading, spending, or G5 advancement.

The model returns one `g4-authoring-unit-intent/6` object for its assigned
public unit. It selects declared variables, one versioned recipe and typed
endpoint for each history intent, one versioned recipe and typed endpoint for
the current route, and an answer justification. The assigned id, stratum, and
open family must be copied exactly.

The host derives the start expressions, rule sequences, bindings, premises,
costs, completion records, intermediate states, renderings, and replay traces.
The host never replaces an invalid model choice or searches for a different
route. Schema admission, expression admission, route construction, endpoint
checking, staging, assembly, identity calculation, and return validation are
separate boundaries.

Every response is retained as an attempt. A rejected or interrupted response
does not reach staging. A staged unit is not a completed package. Completion
requires the frozen population to assemble, receive identities from the pinned
executable, and pass the content-free open return validator.
